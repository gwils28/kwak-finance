# 0003. React + TypeScript + Vite frontend

- Status: accepted
- Date: 2026-10-06

## Context

The UI is rich (tables, charts, forms) and must match the blog's visual identity.

## Decision

React 19, strict TypeScript, Vite, Tailwind v4 with the blog tokens, shadcn/ui, TanStack Query/Router, Biome.

## Alternatives rejected

SvelteKit, Vue, HTMX.

## Consequences

Dash is limited to exploratory analytics pages (phase 4).
